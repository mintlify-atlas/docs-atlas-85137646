MeetCost is a self-hosted meeting cost estimator for Google Meet, Zoom, and Microsoft Teams. It calculates the real payroll cost of meetings in real time — at scheduling, after the meeting, and in periodic team digests — all running on your own infrastructure with salary data encrypted under a key only you hold.

## Why MeetCost?

A recurring 8-person weekly sync feels free at the point of scheduling. It is not — it is roughly £40,000 a year of payroll. Every tool that shows you this number is SaaS, which means shipping salary data to a third-party cloud. MeetCost is the same idea, self-hosted: the calculation runs on your infrastructure, against your database, under your encryption key.

## How it works

```
  ┌─────────────┐  ┌───────────┐  ┌────────────┐
  │ Meet add-on │  │ Zoom app  │  │ Teams app  │     thin clients — no pay data
  └──────┬──────┘  └─────┬─────┘  └─────┬──────┘
         └───────────────┼──────────────┘
                  HTTPS, your domain only
                         │
              ┌──────────▼───────────┐
              │   MeetCost service   │   rate engine · directory sync · reports
              └──────────┬───────────┘
                         │
                   ┌─────▼─────┐
                   │ Postgres  │   pay data, encrypted with your key
                   └───────────┘
```

Three thin clients — a Google Meet add-on, a Zoom app, and a Teams app — talk exclusively to your MeetCost backend over HTTPS on your own domain. Pay data never reaches the client. Every cost response is redacted server-side for the specific viewer before it leaves the service.

## Get started

<Steps>
  <Step title="Clone and configure">
    Clone the repository and copy the example environment file.
    ```bash
    git clone https://github.com/SedemBalfour/MeetCost.git && cd MeetCost
    cp .env.example .env
    ```
  </Step>
  <Step title="Generate an encryption key">
    MeetCost encrypts every pay figure with a key you supply. Generate one now and paste it into `.env`.
    ```bash
    docker compose run --rm meetcost meetcost genkey
    ```
  </Step>
  <Step title="Start the service and seed demo data">
    ```bash
    docker compose up -d
    docker compose exec meetcost meetcost seed-demo
    ```
  </Step>
  <Step title="Open the admin console">
    Visit `http://localhost:8000/admin`, click **Get a development token** with `ada@example.com`, and you're in. Try the `/api/v1/estimate` endpoint to see a live cost estimate.
  </Step>
</Steps>

<Note>
  The Docker Compose setup uses development auth and SQLite. See [Deployment](/deployment/docker) for a production-grade setup with Postgres and OIDC.
</Note>
